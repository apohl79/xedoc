Pair a host

Hosts in external network mode and hosts reached through the sendnix bridge require pairing. Internal direct connections only need sign-in.

On a trusted computer connected to the host

In Xedoc, open the host and sign in as an administrator. Choose File → Pair Device… and create an invitation.

If you only have terminal access to the host, run this command there:

xedoc-remote-agentd device-pairing invite

For a direct host in external network mode, use host-gui pair-device instead of device-pairing invite.

For first-time setup, use Pair Device on a trusted computer to check for an unused sendnix bridge port, then run device-pairing setup on the host to install and start its connector. Each public port serves one host; all devices pairing with that host share it.
